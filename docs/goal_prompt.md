## 3. 已确定且不能误迁移的模型合同

- 四麦轮自由底盘，五个主动臂轴joint1…joint5，另有独立两指开合驱动。
- 相机固定在link4分支。joint5转夹爪、两指开合都不直接改变相机位姿。
- TCP固定在夹爪导杆结构；q5改变TCP朝向和相机→TCP变换，开口不改变固定TCP。
- 旧末端规划中“将相机改挂TCP、保持相机/TCP固定外参”的要求已被本轮用户澄清取代。不得迁入该变更。
- 使用实际动态臂模型，不能误用固定臂驾驶档；有效限位由编译模型和明确的软件限制发布。
- 用户角与模型角分开；m/rad为内部单位，界面可mm/deg。约±90°线束仅是旧讨论中的候选软件边界，不能冒称本次实物已标定。
- 不固定底盘、不瞬移运行态机器人或目标、不吸附物体、不关闭碰撞来使案例通过。初始化Reset可以设置初态，但须作为Episode边界。

## 5. 实现行为

提供独立可启动的MuJoCoBackend和mock后端。新工程不能靠修改sys.path访问旧工程或读取旧experiments才能运行。

所有输入统一经过身份/所有权/序号/有效期、有效限位、轨迹和碰撞检查，再由有限力控制器执行。命令租约使用接收端单调时钟；旧Episode、重连前请求和取消前计划不得恢复。

请求TTL限制首次下发；长计划由会话心跳维持权限，不反复启动旧轨迹。TCP和关节目标互斥占arm组，夹爪也归该组。明确允许轮地和批准阶段的指腹—目标接触，检查其余非预期碰撞和持物包络，不能全局禁碰撞、拒绝抓取所需接触或忽略载物与环境碰撞。

界面提供：

- 可旋转、缩放、平移的整车三维视图，与物理模型同源。
- 按住W/S前后、A/D横移、Q/E转向，松键/失焦/断连停止；输入框不触发驾驶。
- 五关节和夹爪滑块、TCP位置输入及目标拖动。
- 默认预览→检查→执行，目标、计划与实际状态明显区分。
- 位置优先求解、姿态残差、关节余量、拒绝原因和实际到位反馈。
- 停止、取消、软件停止复位、Reset、录制、阶段标记及只读回放。

首版保留现有DLS和轨迹作为后端；Viser用于交互显示，可按需适配显示组件。不要为首包盲目引入Mink或升级全套环境。任何替代方案需满足相同行为，不能用视频截图冒充三维交互。

旧DLS有完整朝向代价，须适配为位置容差优先、姿态可放松并单独报告残差；未输入朝向时使用提交时实际姿态软偏好，不默认单位旋转。预检与执行必须对应同一条时间参数化轨迹，不能检查直线插值却执行逐轴不同斜坡；实际跟踪偏离越界时停止/保持。

世界目标提交后保持固定；手动驾驶取消旧自动轨迹，不默认自动补偿臂，停稳后重新规划并显式执行。软件停止需锁存，保持/制动策略可解释，不默认松开持物夹爪。暂停不等于实测停稳。

## 6. 数据闭环

按interface_contract_v1保存：

requested → approved → dispatch → actuator_reference → feedback。

拒绝/过期请求也保存，用command_id和control_tick关联，不把反馈当作默认动作标签，不把旧applied字段直接视为执行器下发时刻。

记录RGB、米制Depth/有效掩码、激光、IMU、编码器、关节、图像时刻FK/标定引用、模式与阶段、任务语言、操作者及所用视图、结果与异常。原始图像不叠加真值或交互手柄。

G1可显式使用GT_DEBUG控制调试；world_sim与map不混用，Oracle/真值和默认观测分开。现有A1Snapshot含truth，不得整对象透传给未来策略。没有估计输出时记不可用，不从真值补齐。

Recorder具备有界队列、可靠资产引用、错误通知、关闭排空和完整结尾。正式采集写盘失败触发受控停车并标记无效Episode；界面录制状态来自Recorder确认。

正式录制须在起点可靠保存后才放行运动；关闭录制先停车并结束片段，重开使用新片段身份。关闭程序时保留停车过程的必要物理与反馈，确认停稳/超时后再停采样和排空。写盘失败、记录完整性和物理任务结果是不同字段；尾部写不成时由validator拒绝完整记录。

回放只读，不执行动作；可播放不等于动力学精确复现。完整性、任务结果、训练资格分别报告。

开发agent经界面操作的来源记agent_ui；人类示教记human_teleop，脚本/合成数据单列。第三人称辅助的示范不自动被认定为仅腕部相机可学。
