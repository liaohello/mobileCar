## 2. 下一步为什么先做G4A-1

导航到达不代表目标在link4画面可见、深度可靠、夹爪能到达或动作已适合学习。

现有G1成功主要来自agent_ui/third_person_3d；G2B报告明确D2是执行参考型开发出口，未验证部署动作适配器，也未正式检查link4可观测性。当前资格函数主要核对来源、结果、数量、export和view，不能把配置里的相机挂载、任务覆盖、父任务划分规则当作已全部实现。

下一Goal定为**G4A-1：固定底盘近场抓取与示教采集准备**。具体完成：

1. 一个可见、可达的20mm方块抓取抬升任务；
2. 受限link4 RGB-D/本体视图及来源明确的操作入口；
3. 与未来策略共用的六维关节/夹爪目标接口；
4. 原生采集、动作因果链、阶段可观测性与独立物理评分；
5. 三条开发成功示范及三类中止/Reset案例。

本Goal不依赖真人在场。agent或脚本产出的记录明确保持自身来源，全部使用dev用途，training_qualified=false；人类示教资格留给后续实际人类采集。既不凑Episode数宣称可训练，也不把开发成功当策略成功。

## 5. 重要实现选择

- **底盘保持物理自由。** 初始停车位显式准备，本阶段不要求Nav2前置导航；零底盘命令、测量停稳和操作权限替代焊死底盘。设置park_source=prepared_pose，不能称导航交接已验收。
- **相机保持link4。** joint5影响TCP相对相机关系，两指开合不改变固定TCP；不改挂TCP、不加第二相机来绕过可见性问题。
- **观测使用独立白名单。** RGB、米制Depth及深度有效mask、关节/开口、capture身份与FK/标定；不消费目标真值、第三人称场景、实例分割真值、接触Oracle或完整diagnostics。深度有效mask与物体分割mask明确区分。
- **动作重新定义而不篡改G2B。** 建议5Hz、五轴绝对用户角rad+绝对夹爪宽度m。冻结requested→approved→dispatch→actuator reference及每层延迟；本轮动作标签为新合同的目标层，历史G2B执行参考不直接当同一动作。
- **教学辅助保持来源。** 可复用滑块/TCP预览；若增加图像点选辅助，只用画面像素、实际Depth、capture时FK和标定。教师可用Depth时，不能宣称该数据已证明RGB-only可观察性。
- **不扩建视觉专家系统。** 本轮不要求训练检测器、自动目标搜索或全自动抓取策略。开发示范可由agent实际操作服务器受限界面完成，明确agent_ui；脚本仅按声明的可用输入操作，来源scripted。
- **不把map坐标当毫米级近场定位。** 近场只用图像时刻局部相机→arm_base几何；不让SLAM全局修正逐次移动近场目标。

## 6. 有限验收

正式6例，建议每例≤120s仿真时间、≤180s墙钟时间，正式前冻结：

| case | 预期 |
|---|---|
| M01 中央方块 | 受限视图抓取，抬升≥0.05m、双侧有效接触保持≥2s |
| M02 小横向偏移 | 约10mm偏移，重新观察后抓取成功 |
| M03 小纵向偏移 | 约10mm偏移，重新观察后抓取成功 |
| M04 图像/Depth失效 | 关键阶段中止、保持最后安全目标且不自动松爪；恢复不续旧动作 |
| M05 Stop/人工接管 | 停止或接管后旧控制帧拒绝，显式新权限才可再操作 |
| M06 Reset | 新Episode/epoch拒绝旧帧/旧预览，重新初始化后可接纳新的安全目标 |

场景变体在Episode前设置，运行中不改qpos、物体位置或接触。三条成功开发记录不是成功率估计，所有失败、准备和修复重试单列。

成功例操作期间自由底盘漂移建议≤0.01m、yaw≤2°；进入操作前采用已验收停稳门≤0.01m/s、≤0.03rad/s持续≥0.6s。阈值正式前冻结，不因失败缩小footprint、关闭碰撞、改变摩擦或放宽成功门。

软件/GUI子门：标定与capture变换；纯六维安全目标实际执行；错误单位/顺序/越界/过期/旧身份拒绝；底盘移动与近场权限互斥；关键阶段图像有效性和可观测性；首中末和闭爪/抬升的动作追溯；父Episode切分防漏；源哈希不变；真实服务器受限GUI操作。

原生RGB-D目标5Hz，先保持G2A既有capture/arrival/persist语义；报告全部窗口、样本唯一性、实际频率、年龄和缺口，不复制帧补频率。当前任务以RGB-D profile验收，RGB-only资格单列为未验证。

## 7. 交付与范围控制

交付近场接口、G4A-1独立profile/case清单、使用说明、六例/子门报告、阶段可观测性证据、开发Episode索引、来源和资格原因、失败记录、agent回执及新release/aggregate。新资格门逐项实现并列出PASS/FAIL/NOT_EVALUATED；既有G2B资格逻辑保持历史结果不变。

仅生成小型可追溯的对齐预览/sidecar，不在本Goal安装或重跑LeRobot导出、编码、loader或训练。没有正式导出就将export_valid标为NOT_EVALUATED，不能把原生format_valid当LeRobot有效。

所有安装、构建、MuJoCo/渲染、自动浏览器、测试和指标计算在服务器；本地保存源码/资产/配置/锁及默认≤20MB小证据。原始媒体与日志留服务器，不触碰旧运行环境和历史记录。

导航实现/地图未改则不重跑G3B十例；共享权限或后端改变时只补相关导航控制回归，确有影响才扩大。保留历史provenance例外，为当前release建立实际文件hash门；不将排除项写成通过。
