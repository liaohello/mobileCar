## M0 冻结决策

- 底盘 `[vx, vy, wz]` 为 base_link 下前/左/逆时针正。
- 用户关节固定为 `joint1..joint5`，消息单位 rad；模型角只在快照诊断字段出现并在后端转换。
- 夹爪宽度为两指净开口 m；TCP 固定于 `guide_rod_link`，不随开口变化。
- 相机唯一父体为 `link4`，不采用旧工程可选的相机挂 TCP 实验路径。
- TCP 未给朝向时以提交时实际姿态为软偏好；位置优先。
- 命令 TTL 约束首次 dispatch，会话租约约束持续运动。
- 软件停止锁存；Reset 产生新 Episode；关闭夹爪时停止不自动松爪。
- 普通运行和默认策略观测不含 `world_sim` 真值；Oracle 仅写 assessments。
- 首轮超时：单动作 30 s、单 Episode 300 s、停车确认 5 s、stopped 速度阈值连续 0.5 s。
- 运行时端点与场景描述按 `docs/runtime_api_v1.md`；同源模型身份为 `Capabilities.model_sha256 == SceneManifest.model_sha256`。
- `EventSink` 同时接收 `EventRecord` 与 `SensorObservation`；`EpisodeRecorder`/`ReplayReader` 协议只由应用装配使用。

## 集成顺序

M1 mock 合同、UI 与数据闭环 -> M2 MuJoCo 动力学与动态相机 -> M3 录制故障/回放 -> M4 遥操作移动抓取与分层验收。
