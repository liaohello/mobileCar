## 物理与控制

- 初版纯位置 PD 在重力下有约 10 mm 稳态下垂。加入由 `qfrc_bias` 计算、仍受执行器 `forcerange` 限幅的重力/科里奥利前馈后，三个 TCP 实际位置误差均小于 1 mm。
- 0.13 m 抓取高度只擦到方块上沿，抬升时滑落。改为停稳位置约 0.14 m、TCP 抓取高度 0.127 m、较慢同步轨迹，并在双侧接触后等待夹持稳定；最终抬升 96.0 mm、保持 8.65 s。
- 路径预检发现部分下降目标与台面接触；执行前拒绝碰撞计划，没有通过关闭碰撞或放宽阈值绕过。
- no-realtime 测试中停稳持续时间误用墙钟。停稳判定改为仿真时间连续 0.5 s，实时运行行为不变。
- 浏览器 headless 软件 WebGL 会阻塞主线程和 `click()` 数秒，导致心跳/驾驶命令漏发或租约到期。最终验收将同源三维视图留在浏览器，动作由同一 `agent_ui` 会话通过版本化 API 定时执行；键盘、滑块和拖动仍由独立 Chromium 交互测试覆盖。
- 键盘刷新、心跳与计划命令曾并发发送并造成序号乱序。UI 现在串行化运动命令；租约使用独立 `/api/v1/lease/renew`，不占用动作序号。

## 应用与数据

- 激光无回波值在 JSON 中不能直接表示真实 NaN，详情 API 曾返回 500。只读 API 现把非有限值显式转换为 `null`；原始 Depth 文件的 NaN 语义不变。
- UI 回放资产 URI 已含 `assets/`，后端又重复拼接一次导致 404。资产端点现兼容 Episode 相对路径，原始 RGB 响应已验证为 200/image/png。
- 浏览器自动脚本被实时快照轮询覆盖 phase select，误记录一次异常片段。脚本改为原子设置并执行；该异常片段的完整记录保留为 failure 证据。
- `.venv` Playwright 1.55 与本机 Chromium 1243 不匹配。测试依赖锁定更新到 Playwright 1.63.0，重新构建后 headless Chromium 测试通过。
- 并行复核后适配文件哈希发生漂移；最终重新生成 provenance 清单并新增完整性测试。
- backend 未录制时曾持续把诊断 RGB-D 写入中转目录。现仅在 Recorder gate 确认 RECORDING 时写盘/发布原始资产，调试渲染仍可显示；正式 Episode 不受影响。
- 首次正式录制在停录边界出现 1 个孤立 RGB 帧。Recorder 现要求每个 RGB/Depth 按相同 `(stream_id,sample_id)` 成对，backend 在停录前 quiesce 传感器提交锁；最终 87 组 RGB/Depth/Mask 完全成对。
