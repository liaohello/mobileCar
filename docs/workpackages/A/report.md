# A 后端工作包记录

日期：2026-10-17。合同：`mobilecar-1.0`。

## 协作情况

首次派发的 A 线程退出；第二次 A 线程连续两次只返回空任务，没有产生可验收实现。按实施计划中“委派不可用时记录原因并串行继续”的规则，主负责人接管 A 的独占范围，并保留本记录，不把该实现声称为独立 A agent 的成果。B/C 仍由各自执行线程完成。

## 已实现

- 独立生成/加载四麦轮自由底盘、5 主动 DOF 动态臂、独立夹爪、`mobile_pick` 场景和 23 个 STL；相机位于 `link4` 分支，TCP 固定 `guide_rod_link`。
- `MockBackend` 与单物理线程 `MujocoBackend`，统一实现 `RobotBackend`/`EventSink` 接口和场景资产端点。
- 命令身份、会话序号、幂等、接收端 TTL 窗口、500 ms 租约、base/arm 所有权、接管、停止锁存、Reset、动作超时。
- 四轮力矩速度伺服、五轴/夹爪有限力 PD、重力/科里奥利前馈、同步五次轨迹、DLS IK、路径碰撞预检及执行身份复核。
- 真实轮地接触和批准抓取指腹接触；其余机器人-环境接触终止并锁存。
- RGB8、米制 NaN 深度、有效掩码、2D raycast、IMU、编码器、关节反馈、图像时刻 FK/TCP-相机变换；渲染线程只读副本，不推进物理。
- 命令链事件 requested/approved/reject/dispatch/actuator_reference/feedback；拒绝、过期、取消与租约到期可追溯。

## 真实物理与正式 Episode

- 页面等价底盘低速输入约 2.3 s 到达 base x≈0.110 m，停稳阈值通过。
- 最终成功 Episode 中，三个世界 TCP 目标实测位置误差分别为 0.231 mm、0.055 mm、0.631 mm。
- 夹爪 0.018 m 闭合后建立双侧接触；真实方块抬升 0.09597 m，并由隔离 Oracle 证明连续保持 8.65 s。
- 为消除探针观察到的下降路径台面擦碰与持物滑移，使用更靠前的停稳位置、0.127 m 抓取 TCP、较慢同步轨迹和有限力夹爪稳定参数；未放宽验收阈值。
- 正式成功 Episode：`episode_4414a5ec8ae645d29d8e7df7826160cb`。
