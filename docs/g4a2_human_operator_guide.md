日期：2026-10-18。此页是 H0 准备说明；只有用户本人操作产生的三条记录才进入 H1，
agent 的自动页面测试、fixture 和脚本记录全部保持 automation/dev 来源。

## 1. 连接

采集页只绑定服务器 `127.0.0.1:8792`，不开放公网。请在本地已有 SSH 连接上建立端口转发，
使用与 `remote.md` 相同的 SSH 用户、端口和私钥（不要把私钥或口令发给 agent）：

```text
ssh -N -L 8792:127.0.0.1:8792 -p 37694 liaozhengyan@39.96.32.164
```

保持该 SSH 会话运行，在浏览器打开：

```text
http://127.0.0.1:8792/g4a2
```

页面只显示 link4 RGB、Depth 有效率和中心深度、本体五轴/夹爪与操作控件，不显示
world_sim 物体真值、Oracle 接触、第三人称画布或完整 diagnostics。

## 2. 每条真人 Episode 的操作顺序

### 先选对页面

- `http://127.0.0.1:8792/`：原整车遥操作页面，含第三人称三维视角及底盘驾驶。W/S前进/后退，A/D左右平移，Q/E转向；也可按页面对应按钮。该页面仍遵守录制、停车锁存及权限门，按键存在不代表可绕过这些门。
- `http://127.0.0.1:8792/g4a2`：停车抓取采集页面，只操作机械臂/夹爪；本次固定底盘采集不在此提供非零底盘命令。关节滑杆不是小车前后左右。
- 从近场采集切换整车驾驶前，先点“停止并结束”，撤销近场许可并关闭当前记录。整车第三人称辅助数据保留自身视图来源，不自动计入受限RGB-D示教资格。

若RGB尚未正常显示或画面闪烁，先不要发送目标。`RECORDING`只是录制状态，不表示图片已经显示成功。中央深度无效表示中心像素没有有效深度，不等于整张图片无效或目标已经可见。

1. 点击 **开始真人录制**，等待顶部状态显示 `RECORDING`，等待 RGB 图像和 sample 出现。
2. 点击 **确认本人操作**；确认文字应显示 human session ID。
3. 等待图像稳定，点击 **启用近场权限**；确认权限显示 authorized。
4. 用五轴滑杆和夹爪滑杆选择目标；每次改变目标后点击 **发送六维目标**。也可以点击
   **开始 5Hz**，但这仍只发送你当前明确选择的六维目标；页面失焦会停止发送。
5. 接近方块、闭爪、抬升并保持至少 2 秒。完成后点击 **停止并结束**。停止只保持最后
   安全目标，不自动张爪。

每次开始新 Episode 前刷新页面或点击取消/停止后重新确认本人操作。不要在未确认本人操作时
点击发送；不要用脚本或浏览器自动化代你完成 H1。

## 3. 三条 H1 试点

1. **成功 1**：中央布局，完成一次抓取抬升和保持。
2. **成功 2**：中央或小偏移布局，重新观察后完成抓取抬升和保持。
3. **取消/失败**：主动取消、停止或执行一个不成功试点；失败/取消原样保存，不重录覆盖。

完成后请告诉 agent“H1 三条已完成”。agent 会只读检查 Episode、human intent、显示
sample、普通六维目标流、权限、dispatch、实际 tick、RGB-D 和物理评分，不会补写或替改
你的动作。H1 通过后才讨论正式 24 条采集。
